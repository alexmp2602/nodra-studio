# Nodra Studio

Sitio web oficial de Nodra Studio, estudio de diseño y desarrollo digital.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4

## Desarrollo local

```bash
npm install
npm run dev
```

Abrí [http://localhost:3000](http://localhost:3000) en el navegador.

## Producción

```bash
npm run build
npm start
```
